# THƯ MỤC SOURCE CODE DỰ ÁN

Mã nguồn hoàn chỉnh của đồ án bao gồm 2 phần chính:

1. **`backend/`**: 
   - Mã nguồn Backend viết bằng **NestJS** (TypeScript).
   - Đầy đủ Controllers, Services, Modules, DTOs, Entities, Guards, Filters.
   - Kết nối cơ sở dữ liệu PostgreSQL.

2. **`frontend/`**:
   - Mã nguồn Frontend viết bằng **Next.js 16** (App Router & TailwindCSS).
   - Hệ thống trang giao diện người dùng và quản trị trực quan, responsive.

3. **`frontend.zip`**:
   - Bản build Static Export tối ưu sẵn sàng giải nén vào thư mục `public_html` của hosting DirectAdmin.
